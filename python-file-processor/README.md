# Python File Processor

This project reads a text input file, processes the contents, and writes a final output file.

## Usage

1. Install dependencies:

```bash
poetry install
```

2. Run the processor:

```bash
python main.py sample_input.txt output.txt
```

3. Check `output.txt` for the processed results.

## Behavior

The example implementation normalizes each line by stripping whitespace, converting text to uppercase, and writing numbered output lines.
